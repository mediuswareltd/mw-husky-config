# About MW Husky Config

## Who maintains it

MW Husky Config is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/mw-husky-config](https://github.com/mediuswareltd/mw-husky-config).

## Why it exists

A reusable Husky configuration package for consistent pre-commit quality checks and conventional commit messages.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/mw-husky-config/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
