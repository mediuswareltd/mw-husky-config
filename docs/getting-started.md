# Getting started

Install and run **MW Husky Config** locally.

## Prerequisites

- Working knowledge of JavaScript
- Git and a terminal

## Install

```bash
npm i --save-dev @mediusware/mw-husky-config
```

## Quick start

```bash
npx mw-husky-config
# or follow README installation modes
```
