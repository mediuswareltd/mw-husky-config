# Guide

## What it is

A reusable Husky configuration package for consistent pre-commit quality checks and conventional commit messages.

## Stack

`Husky`, `npm`, `Conventional Commits`

## Capabilities

### One-command setup

Install package and auto-configure hooks.

### Pre-commit checks

Prettier, ESLint, cspell, secretlint, npm audit.

### Commit-msg lint

Conventional commit types and length rules.

### Cross-project consistency

Same hooks across many repositories.
